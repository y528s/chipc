City & Hackney IPC Members Portal — rebuild plan on a page

What we're changing, what stays the same, and how we get from this prototype to the live site — for sign-off.

The goal

Rebuild the IPC area (Members Portal) to match the approved design (Design 1 — The IPC Hub): search-first, consistent across every page, and editable by IPC admins directly on the page — no developer needed for day-to-day content changes.

What changes / what stays

Changes

  • Every portal page gets the approved design — one consistent header, search and card system.
  • IPC Documents adopt the pattern designed for the GP Section: search-first library, type filters, popular / recently-updated panels, and a proper document page with in-browser preview.
  • Front-end editing — admins toggle "edit" on any page and change text in place (try the ✎ Admin: edit this page button on the prototype).
  • One consolidated admin area — a single, tidy back end for the whole IPC area instead of scattered edit screens.

Stays the same

  • Bulletins — content and weekly publishing workflow are unchanged; only the page chrome is refreshed.
  • All existing content — documents, contracts, policies migrate over; nothing is lost.
  • Logins — members keep their existing accounts.
  • The GP Section — already designed; the portal now matches it.

Every page in the new portal (all clickable in this prototype)

🏠 Portal home — search hero, quick access, popular / recent, events & news
▤ Bulletins — as-is content, refreshed chrome
✎ Contracts → contract page (e.g. Duty Doctor) — resources, lead, about
▣ Documents → document page with preview — GP-Section pattern
✓ Policies — owners, versions, review dates
☺ Staff Bank — find work / find staff
🩺 GP Hub — the already-approved GP Section design (blue theme)

How editing will work (WordPress)

  • The site is rebuilt as a WordPress theme matching this prototype exactly — each block here maps to an editable block in WordPress.
  • Admins edit the front page (and every page) in place; editors see the page exactly as members do.
  • Documents, contracts and policies become structured content types — upload a file, pick the contract/topic, and every listing, search result and "recently updated" panel updates itself.
  • One consolidated IPC dashboard in the back end: bulletins, documents, contracts, policies, events and news in a single menu, with clear roles for who can edit what.

Getting to live

  1. Now — review this prototype. Click through every page, try the admin edit button, and confirm the design and structure.
  2. Sign-off. Stakeholders approve the design and the plan on this page.
  3. Build on staging. WordPress theme + content types built to match the prototype on a private staging server; existing content migrated across.
  4. Test. Admins test editing; a small member group tests finding documents. Fixes applied on staging.
  5. Go live. Staging is pushed to the live server in one switchover; the old site is kept as a rollback for 30 days.

The ask

Approve the design and this plan so the staging build can start. Feedback on any page of the prototype is welcome before sign-off — everything you see is still easy to change.
